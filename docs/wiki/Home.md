# VinoGuessr development wiki

VinoGuessr is a service for blind wine tasting: people create events, set questions, answer them, get scored, and build a season rating. The API and PostgreSQL are the source of truth.

- [Architecture](Architecture)
- [Development](Development)

`docs/wiki` is the reviewed source of truth for the wiki, and content changes go through PRs. If the wiki needs initializing, create the first page from GitHub's Wiki tab, then sync the content of a reviewed commit.
